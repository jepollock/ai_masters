\subsection{Question 1}

Process Order:

choose(a,b) : a > b ? a : b. If "a" is after "b", it is the earliest start time, otherwise the earliest start time is b.

The requirement that the timestamps are in t1...tn order is an additional constraint, keeping later jobs from starting early even thoug the machine is available.
